# Práctica Profesional - Trabajo Práctico 2 (51993)

Este repositorio contiene las resoluciones correspondientes al Trabajo Práctico número 2. El objetivo principal de estos ejercicios es la práctica y comprensión del manejo de **Eventos** (Events) a través de código.

## 📁 Estructura del Proyecto

El repositorio está organizado en tres directorios, uno para cada ejercicio solicitado:

* **`TP2_Ejercicio1_Eventos/`**: Archivos y lógica del primer ejercicio.

* **`TP2_Ejercicio2_Eventos/`**: Archivos y lógica del segundo ejercicio.

* **`TP2_Ejercicio3_Eventos/`**: Archivos y lógica del tercer ejercicio.

## 🛠️ Tecnologías y Herramientas

Dado el enfoque en el manejo de eventos, este proyecto utiliza principalmente:

* HTML5

* CSS3

* JavaScript (Manejo del DOM y Listeners de Eventos)

## 🚀 Cómo ejecutar el proyecto

1. Clona este repositorio en tu máquina local:

   ```
   git clone https://github.com/catalinagimenez604-wq/PP_TP2_51993.git
   
   ```

2. Navega a cualquiera de las carpetas de los ejercicios.

3. Abre el archivo `index.html` (o el archivo HTML correspondiente) en tu navegador web preferido para interactuar con el código.
